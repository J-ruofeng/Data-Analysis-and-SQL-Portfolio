# AI与多终端数据运营实习作品集 (SQL & Python Cases)

本项目专门用于展示在 **AI工具提效、大模型 Agent 场景、多终端业务生态数据运营** 中的底层代码实操能力与分析逻辑。

## 🚀 核心技术栈
- **数据查询与建模**：SQL (窗口函数、多表聚合、多终端行为统计)、Excel 高级数据建模
- **开发与数分库**：Python (Pandas, NumPy), Flask, Git
- **大模型与提示词**：Prompt Engineering, Agent Skills 配置, 自动化工作流设计

## 📂 目录结构与案例说明

### [1. SQL 查询语句案例 (01_SQL_Query_Cases)](./01_SQL_Query_Cases/)
- **`netease_music_dau.sql`**：模拟网易云音乐等多终端业务场景，编写包含 `WINDOW FUNCTIONS`、`CASE WHEN` 及多级 `JOIN` 的复杂语句，清洗分析活跃、内容消费、及付费转化指标。
- **`text_to_sql_eval.sql`**：针对 AI 问数场景，输出配合大模型进行 Text-to-SQL 输出评估、Badcase 分类、以及指标语义层（Metadata）定义的 SQL 数据校准基准。

### [2. Python 自动化与数据分析 (02_Python_Data_Analysis)](./02_Python_Data_Analysis/)
- **`user_behavior_pandas.py`**：熟练运用 `Pandas` 对 10万+ 行为矩阵执行自动化数据清洗、缺失值打标与多维留存率核算。
- **`automated_wps_ai.py`**：通过轻量化脚本和 Prompt API 调用，跑通“自动化数据处理-特征提取-结构化文档产出”的业务闭环。
